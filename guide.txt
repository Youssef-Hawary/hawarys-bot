HAWARY'S BOT - SETUP GUIDE
==========================

You install it once on the bot PC. Workers install nothing.


A. INSTALL ON THE BOT PC (once, about 2 minutes)
------------------------------------------------
1. Download the installer:
   https://github.com/Youssef-Hawary/hawarys-bot/releases/latest/download/HawarysBot-Setup.exe

2. Open it.
   If Windows says "Windows protected your PC": click "More info", then "Run anyway".

3. Click "Next" until it's done.
   On a café PC that resets when it restarts, choose a folder on a drive that keeps
   its files, for example D:\HawarysBot.
   When Windows asks for permission (firewall), click "Yes".

4. The bot starts by itself and opens its own browser with two tabs:
   Eldorado and the dashboard.


B. FIRST TIME ONLY
------------------
1. In the dashboard tab: create the OWNER account (pick a strong password).
2. In the Eldorado tab: log in to your seller account. Keep the site language ENGLISH.
3. Click the puzzle icon at the top right of that browser -> "Hawary's Bot"
   -> "Connect Eldorado API (owner)". You should see: Eldorado API connected.

The extension is already installed and connected. Nothing else to set up.


C. EVERY DAY
------------
Double-click the "Hawary's Bot" icon on the desktop. That's all.
- It updates itself when it starts.
- A small "Hawary's Bot" window starts minimized in the taskbar.
  Keep it open. Closing it stops the bot.
- The PC won't go to sleep while the bot runs.
- Use the bot's own browser for the Eldorado tab the bot works with.


D. WORKERS
----------
Nothing to install.
1. Dashboard -> "Team & pay" -> "Add worker" to make their account.
2. At the top of that page is the "Workers' link", for example:
       http://192.168.88.5:8787
   Workers open it on any PC or phone in the café (same router or Wi-Fi)
   and log in. Save it as a bookmark.
3. They use Eldorado in their normal browser, like before.

If the link doesn't open on another PC:
- That PC must be on the same network (same router). Not on this PC's hotspot.
- Use the link that starts with the same numbers as that PC's address
  (cmd -> ipconfig -> IPv4 Address).


E. TEST WITHOUT RISK (dry run)
------------------------------
1. Dashboard -> Settings: set the Eldorado fee %, and keep "Dry run" ON.
   (Optional) Add a Discord webhook to get "new order" alerts.
2. Dashboard -> Pricing: set your prices.
   Use "Test a request" on the right to check what the bot would charge.
3. Dashboard -> Overview: click "Start bot".
4. Watch "Live offers". New requests show what the bot WOULD offer.
   Nothing is sent to buyers yet.


F. GO LIVE
----------
When the would-offer prices look right (for example after a day):
Dashboard -> Settings -> turn "Dry run" OFF.
The bot now sends real offers with your opening message.
New orders appear on the "Order board". Click "Take" to claim one.


YOUR DATA
---------
Accounts, prices, orders and daily backups are in the "data" folder inside the
install folder (normally %LOCALAPPDATA%\Programs\HawarysBot\data).
Updates and reinstalling never touch it.
Extra copy: Dashboard -> Settings -> Backup & restore -> "Download settings".

Coming from the old setup (ZIP + start.bat)? Close the old black window first.
The new app copies your old data by itself the first time it starts.


IF SOMETHING GOES WRONG
-----------------------
The bot's window stays open and shows the error.
Take a screenshot and send it to Claude.
